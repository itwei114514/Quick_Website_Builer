## 🚀 快速开始

### 方式 1：直接运行（推荐）

```bash
# 安装依赖
pip install Pillow opencv-python

# 启动编辑器
python solution.py
```

> 💡 **核心编辑功能无需任何依赖**，Pillow 和 OpenCV 仅用于图片/视频的编辑器内预览。

### 方式 2：打包为 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --add-data "solution.py;." solution.py
```

## 🎯 功能详解

### 🖱️ 所见即所得编辑器

| 操作 | 方式 |
|------|------|
| **选中** | 左键单击元素 |
| **移动** | 拖拽选中元素 |
| **缩放** | 拖拽 8 个白色控制手柄 |
| **编辑文字** | 双击文字元素进入内联编辑 |
| **右键菜单** | 删除、调整图层顺序（上移/下移） |
| **取消选中** | 点击画布空白区域 |

### 📄 多页面管理（PPT 风格）

- 左侧缩略图面板直观展示所有页面
- **右键页面**：重命名 / 复制 / 删除 / 左右移动
- 两种导航模式：
  - **浮动导航** — 底部固定黑条 + 圆点指示器 + 箭头翻页
  - **页面内嵌导航** — 每页底部显示页码条

### 🎭 16 种文字特效

```
📐 3D 立体      💡 霓虹发光      🌈 渐变文字      ✏️ 描边文字
📳 抖动          🏀 弹跳          🌊 波浪          ⌨️ 打字机
✨ 呼吸发光      🎈 漂浮          🔍 悬停放大      🔄 悬停旋转
🎪 彩色循环      💫 缩放脉冲      🌟 闪烁          ☁️ 浮动上升
```

### 🌌 8 种沉浸式背景

```
✨ 动态渐变      🫧 气泡升起      🌟 闪烁星空      🎊 五彩纸屑
❄️ 飘雪          ✨ 粒子漂浮      还有更多探索…
```

> 所有特效均使用 **纯 CSS + Vanilla JS** 实现，无需加载任何外部库！

### 🖼️ 图片控制

**3 种适应方式：**

| 模式 | CSS | 效果 |
|------|-----|------|
| 原比例留白 | `object-fit: contain` | 保持比例，空白留白 |
| 裁剪填充 | `object-fit: cover` | 裁剪超出部分，填满区域 |
| 拉伸填充 | `object-fit: fill` | 拉伸变形，填满区域 |

**6 种相框样式：**

| 相框 | 效果 |
|------|------|
| 🖼️ 简约白边 | 白色边框 + 阴影，经典照片风格 |
| 📐 浮动阴影 | 大幅阴影悬浮效果，图片浮在页面上方 |
| ✨ 圆角相框 | 大圆角 + 柔和阴影，现代感设计 |
| 🟫 复古画框 | 暖色木纹边框 + 复古色调，怀旧风格 |
| 💡 霓虹光框 | 霓虹光晕，科技感十足 |
| 🎨 软边画框 | 宽大浅色边框 + 柔和阴影，优雅外观 |

### 🎬 视频嵌入

- **本地视频**：自动复制到导出目录或内联为 base64
- **远程视频**：直接引用 URL
- **编辑器内预览**：自动提取视频中间帧（通过 OpenCV），带播放按钮覆盖层
- **导出**：项目文件夹模式自动将视频复制到 `media/` 目录

### 🔗 智能链接

```
输入 baidu.com     → 自动补全为 https://baidu.com
输入 C:\page.html  → 自动识别为 file:///C:/page.html
输入 https://...   → 直接使用
```

支持 `_blank` / `_self` / `_parent` / `_top` 四种目标窗口。

## 📦 导出方式

### 方式 A：自包含 HTML
生成一个 `.html` 文件，**所有 CSS 样式和 JS 交互都内联在其中**，放到任何地方都能直接打开运行。

### 方式 B：项目文件夹
生成 `index.html` + `style.css` + `script.js` + `media/` 视频资源，适合进一步手动编辑和部署。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 保存项目 (.wsweb) |
